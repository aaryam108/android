# Papertrail — Book Tracker (Java)

A fresh native Android app built with Java and Android Views. No WebView, internet permission, or third-party dependencies.

## Features
- Add, edit, and delete books
- Track status: Want to read, Reading, Finished
- Track total pages and current page with progress bar
- Rate books from 1 to 5 stars
- Add notes or favourite quotes
- Search by title or author
- Filter by reading status
- Reading insights: total books, finished, currently reading, wishlist, pages read
- Persistent offline storage using SQLite

## Build
1. Open the `BookTrackerJava` folder in Android Studio.
2. Use JDK 17 and Android SDK 35.
3. Allow Gradle sync to finish.
4. Run on an emulator or Android device (API 23+).

## App details
- App name: Book Tracker
- Package: `com.example.booktracker`
- Language: Java
- Minimum SDK: 23 (Android 6.0)
- Storage: Local SQLite database
